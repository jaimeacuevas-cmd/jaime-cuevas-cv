### 🌐 Ecosistemas Digitales e Infraestructuras de Datos

* 🏛️ **[Mármoles y Bronces](https://marmoles-y-bronces.vercel.app):** Base de datos histórica y ecosistema de presencia sobre la inmigración de artesanos y el patrimonio escultórico en América Latina (1882–1920) [13, 14].
* 🗺️ **[Callejera Madrid](https://callejera-madrid.vercel.app):** Grafo de Conocimiento (Knowledge Graph) que procesa 66.745 tripletas RDF bajo el estándar **CIDOC-CRM (ISO 21127)** e integración a **Wikidata** para auditar asimetrías de género en el espacio público [1].
* 🖼️ **[QUINSAC](https://quinsac.mnba.gob.cl):** Catálogo razonado transnacional y plataforma digital para centralizar la investigación sobre Raymond Monvoisin en Sudamérica (más de 460 obras registradas) [15, 16].
* 🏢 **[Arquitectura Art Déco en Santiago](https://artdeco-santiago.cl):** Proyecto FONDART N° 826072 que transpone el inventario arquitectónico a un ecosistema semántico con Omeka S, Apache Jena Fuseki, IIIF y mediación sonora accesible (WCAG) [6, 14, 17, 18].
* 📜 **[Cartografía Monvoisin](https://www.bibliotecanacionaldigital.gob.cl/visor/BND:666450):** Cápsula geohistórica e interactiva desarrollada en ArcGIS StoryMaps para la Biblioteca Nacional Digital [3, 19].

## 🏛️ Arquitectura y Modelo de Datos
- **CIDOC-CRM (ISO 21127):** Modelado relacional ontológico para eventos curatoriales, personas, instituciones y patrimonio.
- **Linked Open Data (LOD):** Enlaces canónicos controlados hacia Wikidata, ORCID y AAT Getty.
- **Glifos Ontológicos:** `⊙` Personas, `☵` Cargos, `▣` Instituciones, `✦` Proyectos, `⧉` Curatorías, `☲` Publicaciones, `Δ` Formación, `⚯` Portafolio HD.

## 🚀 Despliegue Rápido
1. Clonar el repositorio: `git clone https://github.com/jaimecuevas/cv-interactivo.git`
2. Abrir `dist/index.html` en cualquier navegador web o iniciar un servidor local: `python3 -m http.server 8000`.
